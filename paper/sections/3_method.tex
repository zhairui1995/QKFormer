\section{Method}
\label{sec:method}

\subsection{Q/K Address Construction}
\label{sec:qk_address}

We target the QKFormer attention modules and hook their binary Q/K spike
vectors and token/channel gating signals. For each module, we convert the
observed binary Q and K spike vectors into a compact integer address. Let
$\mathbf{q}_{i},\mathbf{k}_{i}\in\{0,1\}^{d}$ denote spike vectors associated
with a token or channel position. We define an address
\begin{equation}
  a_i = \operatorname{pack}(\mathbf{q}_i,\mathbf{k}_i,\mathbf{g}_i),
\end{equation}
where $\mathbf{g}_i$ denotes the observed token/channel gate code and
$\operatorname{pack}(\cdot)$ is deterministic bit packing. The address is used
only as a diagnostic and adapter index; the original QKFormer backbone remains
unchanged.

\subsection{Feasibility Diagnostics}
\label{sec:e0e1}

The first diagnostic stage measures whether addresses are usable. We report
address coverage, singleton fraction, and conditional response variance for
captured module responses. High coverage and low singleton fraction indicate
that many address buckets are populated by repeated observations rather than
isolated examples.

The second diagnostic stage uses split-aware reconstruction. We calibrate
address-wise response prototypes on training batches and evaluate held-out
validation reconstruction MSE. We compare address LUT prototypes with global
mean and candidate/background means, a coarse token/channel LUT that removes
the Q/K detail bits, and a same-capacity shuffled-address LUT that permutes
prototype values among observed addresses. This stage tests whether the
fine-grained Q/K address is predictive beyond generic smoothing, positional
gating, and table capacity.

\subsection{Hierarchical Backoff QK-LUT}
\label{sec:e5_backoff}

A monolithic LUT over raw Q/K vectors would be vulnerable to dimensionality
explosion. We therefore separate the audit question from the untenable claim
that every full Q/K bit pattern should be materialized. For each module, we
construct a support-aware lookup hierarchy:
\begin{equation}
  \begin{aligned}
  \mathrm{global}
  &\rightarrow \mathrm{token/channel}
  \rightarrow {+}\mathrm{Q/gate} \\
  &\rightarrow {+}\mathrm{K}
  \rightarrow \mathrm{full\ address}.
  \end{aligned}
\end{equation}
Each level has its own prototype table and count threshold. At validation time,
lookup starts from the finest full-address table. If the corresponding bucket is
unseen or below the minimum support count, the prediction backs off to the next
coarser supported level, and eventually to the global mean. We record the
selected level for every validation sample, so missed or weakly supported
addresses cannot silently masquerade as successful full-address lookup.

The hierarchy is evaluated as a reconstruction mechanism rather than as a
hardware or accuracy claim. The full-address table is treated as an oracle
upper-bound control, token/channel lookup as the coarsest structured baseline,
and shuffled full-address lookup as an alignment negative control. We report
held-out MSE, fallback fractions, active entries, and effective table size.
This accounting is deliberately conservative: if the hierarchy needs many
supported entries in the compact address space, we do not count it as solving
LUT compression even if reconstruction improves.

\subsection{Forward-Only Replacement Diagnostic}
\label{sec:e2}

Forward-only replacement substitutes selected module outputs with calibrated
prototype predictions through hooks. This is not the proposed final method. It
is a controlled diagnostic that measures whether replacing a local module
output collapses classification and which stages are most tolerant to LUT-like
responses. We evaluate stage1-only, stage2-only, and combined replacements,
calibration sizes, blend ratios, random calibration subsets, and non-address
controls.

\subsection{Residual LUT Adapter Probe}
\label{sec:e3}

To test whether reconstruction structure transfers to downstream predictions,
we use a trainable residual LUT adapter probe. Given a frozen QKFormer module
output $\mathbf{y}$ and a LUT prediction
$\hat{\mathbf{y}}_{a}$ indexed by address $a$, the adapted response is
\begin{equation}
  \tilde{\mathbf{y}} = (1-\alpha)\mathbf{y} + \alpha \hat{\mathbf{y}}_{a}.
\end{equation}
The table is initialized from shrinkage-calibrated prototypes and then trained
with the backbone frozen. The loss combines cross entropy, KL divergence to the
frozen baseline logits, and local MSE to the baseline module response:
\begin{equation}
  \mathcal{L} =
  \lambda_{\mathrm{ce}}\mathcal{L}_{\mathrm{ce}}
  + \lambda_{\mathrm{kl}}\mathcal{L}_{\mathrm{kl}}
  + \lambda_{\mathrm{mse}}\|\tilde{\mathbf{y}}-\mathbf{y}\|_2^2 .
\end{equation}
This is a probe rather than a claimed production method: the backbone is
frozen, the adapter is small, and every address result is compared to global,
token/channel, and shuffled-address controls. Our conservative setting trains
for two epochs over 128 training batches and evaluates on the full validation
split. We sweep $\alpha\in\{0.025,0.05,0.1\}$ and use $\alpha=0.025$ for
low-disturbance checkpoint, stage, and dataset controls.

We compare \emph{address LUT}, \emph{global mean}, and a weaker
\emph{token-channel LUT}. A same-capacity \emph{shuffled address LUT} preserves
the table-value distribution while breaking address alignment. We additionally
test a global-plus-centered-address decomposition whose zero-mean address table
asks whether address-specific residuals add value beyond global smoothing.
